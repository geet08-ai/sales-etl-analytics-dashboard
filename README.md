# Sales ETL Pipeline & Analytics Dashboard

## Project Overview
A Python-based ETL pipeline that extracts sales data from a CSV file,
validates and transforms the data, and loads valid records into an SQLite database.

## Features
- Extracts sales data from CSV files.
- Validates customer names, quantities, and prices.
- Rejects invalid records.
- Calculates total sales for each order.
- Stores valid records in SQLite.
- Uses SQL queries to analyze revenue and customer orders.

## Technologies Used
- Python
- SQL
- SQLite
- HTML
- CSS
- JavaScript

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Run:

   python main.py
